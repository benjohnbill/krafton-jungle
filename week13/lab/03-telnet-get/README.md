# 03-telnet-get — HTTP를 손으로 치기

## 실행할 명령

```bash
telnet localhost 80
```

연결되면 아래 두 줄을 치고, **빈 줄을 하나 더** 친다(Enter 두 번).

```text
GET / HTTP/1.0
Host: localhost
```

다음에는 `HTTP/1.1`로 같은 일을 한다. 끝내려면 `Ctrl-]` 다음 `quit`.

`telnet` 대신 `nc -C localhost 80`도 된다. `-C`는 줄 끝을 `\r\n`으로 보낸다.

## 볼 것

- 빈 줄을 치기 전까지 서버는 무엇을 하고 있나. 서버는 요청이 끝난 것을 어떻게 아나.
- `HTTP/1.0`일 때와 `HTTP/1.1`일 때, 응답이 끝난 뒤 연결은 어떻게 되나. 응답 헤더의 `Connection` 값을 비교한다.
- 응답 본문은 `curl` 없이 봐도 그냥 HTML 글자다.

## 혼자 하는 변경 과제

실행 전에 예측하고, 하나씩 보낸다.

1. `HTTP/1.1`에서 `Host` 줄을 빼고 보낸다.
2. 메서드를 `GOT`으로 바꿔 보낸다.
3. `nc` 를 `-C` 없이 써서 보낸다.

각 경우의 상태 코드를 적고, 셋 중 하나를 내 서버가 어떻게 처리해야 할지 한 문장으로 쓴다.
