# 04-browser-nc — 내가 서버가 되어 보기

## 실행할 명령

```bash
nc -l 8080
```

Windows 브라우저에서 `http://localhost:8080/hello` 를 연다. 터미널에 요청이 찍히면, 그 터미널에 아래를 직접 치고 마지막에 `Ctrl-C`를 누른다.

```text
HTTP/1.0 200 OK
Content-Type: text/html

<h1>hello from nc</h1>
```

## 볼 것

- 브라우저가 보낸 요청의 첫 줄과 헤더들. `curl`이 보낸 것(02)과 비교해서 무엇이 더 많나.
- 응답을 치는 동안 브라우저는 무엇을 하고 있나.
- `Ctrl-C`를 누르는 순간 브라우저 화면이 어떻게 바뀌나. 연결이 끊기는 것이 왜 "응답 끝"의 신호가 되나.
- `nc -l`은 연결을 한 번만 받는다. 브라우저가 `/favicon.ico`를 따로 요청하면 어떻게 되나.

## 혼자 하는 변경 과제

실행 전에 예측하고, 하나씩 바꿔 응답한다.

1. `Content-Type: text/plain`으로 바꾼다.
2. 상태 줄을 `HTTP/1.0 404 Not Found`로 바꾼다(본문은 그대로).
3. `Content-Length: 5`를 넣고 본문은 더 길게 친다.

브라우저가 무엇을 믿고 화면을 그리는지 한 문장으로 쓴다.
